# Load-Bearing Crates: Sustainability Table

> Verified 2026-07-07. Downloads/versions/reverse-dep counts from the crates.io API; contributor data from the GitHub API (all-time top contributors + authorship of the ~300 most recent commits since 2025-07-07, bots excluded); funding from GitHub `fundingLinks` (GraphQL), Sponsors listings, maintainer profiles, and cited posts. "Bus factor" = effective number of people doing meaningful maintenance in the last 12 months, not all-time totals.
>
> Health: 🔴 red = concrete abandonment/succession risk now · 🟡 amber = single-point-of-failure or stall signal · 🟢 green = no concrete risk signal found. Ordered most-at-risk-first within each layer.

**Cross-cutting facts this table surfaces:**

1. Of 20 rows, **13 have an effective bus factor of ≤2** and **9 have no funding of any kind** attached to the people doing the work.
2. The tauri-apps utility crates (tao, muda, tray-icon, global-hotkey) have quietly changed hands: their author **amrbashir went from ~400 all-time commits to near-zero in the last 12 months** (4 on muda, 1 on global-hotkey, 0 on tray-icon/tao; GitHub profile no longer lists an employer). The volunteer now on top of all four, [Legend-Master](https://github.com/Legend-Master), lists no employer and has no Sponsors listing.
3. The two red rows (fontdb, apple-codesign) are both "boring plumbing with no glory": font discovery for iced/cosmic-text, and the only cross-platform macOS notarization tool.
